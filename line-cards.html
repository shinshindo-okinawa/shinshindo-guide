LINEカード設定

患者様の動き

  1. リッチメニュー「院のご案内」ボタンを押す
  2. カード6枚が届く横にスライドして選ぶ
  3. ご案内ページ「ご案内を見る」で開く
  4. 予約・相談WEB予約・LINE・電話へ

リッチメニューのつなぎ方

おすすめ

A. ボタンでカードを送る

リッチメニューのボタンを「キーワード送信（例：院のご案内）」にして、そのキーワードへの自動応答でカード6枚を返します。トーク画面にカードが残るので、あとから見返せます。

B. ボタンでメニューページを開く

カードを使わず、ボタンから直接「ご案内メニュー」のページを開きます。設定はかんたんですが、トーク画面には残りません。

メニューページ：https://shinshindo-okinawa.github.io/shinshindo-guide/menu.html

GitHub Pagesでの公開

ご案内ページは、GitHubの無料の公開機能「GitHub Pages」で公開します。
GitHubは、Googleアカウントとは別のアカウント（shinshindo-okinawa）で管理して問題ありません。

アカウントshinshindo-okinawa（GitHub）
リポジトリ名shinshindo-guide（公開：Public）
公開アドレスhttps://shinshindo-okinawa.github.io/shinshindo-guide/
メニューページhttps://shinshindo-okinawa.github.io/shinshindo-guide/menu.html

はじめて公開するとき

  1. リポジトリを作るGitHubに shinshindo-okinawa でログインし、右上の「＋」→「New repository」。名前を shinshindo-guide、公開範囲を「Public」にして「Create repository」。
  2. ファイルを入れる「uploading an existing file」を押し、公開用フォルダの中身（index.html・menu.html・data.js・img フォルダなど）をまとめてドラッグして「Commit changes」。
  3. 公開をオンにする「Settings」→ 左の「Pages」→ Source を「Deploy from a branch」、Branch を「main」「/(root)」にして「Save」。
  4. 表示を確認する数分後に公開アドレスを開き、スマホで7ページすべてが表示されるか確認します。
  5. LINEにつなぐ下の「カードの文言」または「Flex Message（JSON）」でカードを作り、リッチメニューのボタンにつなぎます。

内容を変えるとき

  • 文章・コース・スタッフ情報は data.js にまとまっています。ここだけ書きかえれば、全ページに反映されます。
  • 写真は img フォルダの同じ名前のファイルを差しかえます。
  • GitHubで変更したファイルをアップロードし直すと、
    数分で公開ページも新しくなります。

気をつけること

  • Publicのリポジトリは、中のファイルを誰でも見ることができます。患者様のお名前・連絡先などの個人情報は絶対に入れないでください。
  • このページ（院内用）も、アドレスを知っていれば開けます。検索には出ない設定にしています。
  • 写真は、本人の了承を得たものだけを使ってください。
